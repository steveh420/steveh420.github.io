BTC Drive Backup

BTC Drive Backup is a private backup utility being configured for use by its account owner only. It is intended to copy selected versioned technical backup archives from a private GitHub repository into the owner's separate Google Drive account and verify that the copies can be read back correctly.

How authorization is used

Once explicitly authorized by the owner, an automated GitHub Actions workflow may use Google OAuth, the Google Drive API, and rclone to transfer backup archives and integrity receipts to the owner's Google Drive. The granted permissions are shown in Google's consent screen. Selecting a particular backup folder in rclone does not technically restrict the OAuth permission to that folder.

Automated Google Drive transfer is not currently enabled. This website does not provide accounts, accept uploads, access visitors' Google Drive data, or publish the underlying backup files.
