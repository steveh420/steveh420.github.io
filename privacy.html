Privacy Policy

Updated 14 October 2026

Operator and purpose

BTC Drive Backup is a non-commercial utility intended for the private use of its operator, who can be reached through the GitHub profile steveh420. It is not offered to external users.

Data accessed and how it is used

After the Google account owner expressly authorizes the application, its automation may access Google Drive files and metadata within the scopes approved in Google's OAuth consent dialog. The intended activity is to create backup copies of selected private GitHub technical archives in the operator's Google Drive and retrieve those copies to verify their integrity. A configured destination folder is not an OAuth security boundary: the permission scope shown by Google determines the technically available access.

The tool does not use Google user data for advertising, profiling, sale, or trading decisions. It is not designed to transfer Google Drive data to unrelated parties.

Storage, access and sharing

Technical backup archives and related verification receipts are stored within the operator's private Google Drive and may be temporarily handled by GitHub Actions when automation is activated. OAuth credentials will be stored as secrets in the operator's private GitHub repository, rather than published on this website. Google and GitHub necessarily process data in providing their respective storage, authorization and automation services. No private backup archives or Google authentication credentials are intentionally exposed through this website.

Retention, deletion and revocation

Archived files are retained until the operator deletes them or a platform retention policy applies. The operator can delete backup files in Google Drive, delete GitHub artifacts, disable workflows, and revoke authorization in Google Account permissions. Revoking OAuth access prevents future authorized requests but does not automatically remove files already stored as backups.

Public website visitors

This static site does not contain registration forms, embedded third-party advertisements, custom analytics scripts or cookies set by our page code. GitHub Pages may process technical request information under GitHub's Privacy Statement.

Changes and questions

This policy will be revised if the utility's handling of data materially changes. Questions may be directed through the operator's linked GitHub profile. Never share authentication tokens, backup archives, or private account credentials in a public issue or message.
